# Release Notes

### Version 9.5.0 · May 12, 2025

Major feature release introducing the Scripter panel, redesigned navigation, and significant performance improvements.

---

## ✨ Added

### 🐍 Scripter Panel

Full Python scripting environment embedded in Sim4Life with Monaco editor, Jupyter kernel integration, multi-tab file editing, IntelliSense via Pyright/LSP, real-time stdout/stderr output, and code execution with interrupt support.

### 📜 Open Scripts in Scripter

"To Python" scripts now open directly in the Scripter as a new unsaved tab. "To Notebook" actions show a snackbar notification with an Open button linking to JupyterLab.

### 🔧 Routing Toolbox

Ported the Routing tool to headless mode.

### 🧭 Improved Side Menu

GitLab-style navigation redesign with inline expand/hover flyout for multi-child categories, active indicator (glowing vertical bar) for toggled panels, client-side Preferences toggle, chevron badges on collapsed icons with submenus, click-to-pin popover behavior, and header gradient fade.

### 🎯 Selection Info for All Modeling Tools

Multi-input selection now activates compatible tools.

### ⚡ QTech Async API

Offscreen renderer threading support via new async API.

---

## 🛠 Fixed

### 🖱 Mouse Wheel Zoom

Fixed three independent issues causing jerkiness: frontend throttle dropping intermediate wheel deltas, deltaMode not normalized across browsers, and Go channel dropping wheel events without accumulating deltas.

### 📊 Table Filter & Complex Numbers

Added client-side text filter to TableField, reworked complex number display (50 + 0j Ohm notation), replaced expression mode toggle with compact ƒx icon, added loading indicator to RemoteView while waiting for first frame.

### 🎬 Video Playback on macOS

Added explicit `video.play()` call and `webkit-playsinline` attribute to fix Safari on battery/Low Power Mode blocking autoPlay.

### 🪣 Bucket Selection System

Click-to-deselect, shift+click range selection with anchor rows, folder click toggle, glow on assigned dots, proportional bucket sizing, and text overflow handling.

### ⏱ Async Signal Processing Latency

Reduced `ProcessPendingMainAppSignals` interval from 100ms to 5ms, fixing high latency for interactive modeling operations (pick, cylinder creation, measure edit) when async rendering is enabled.
