# Release Notes

### Version 9.4.1 · April 1, 2026

Stability hotfix release addressing multiple workbench freezes and UI issues.

---

## ✨ Added

### Analysis Algorithm Icons

Added missing icons: Extract Eigen Vector, Field Evaluator of Equivalent Sources, Fractional Anisotropy, Parallel Transmit, Neural Sensing, Touchstone File Importer.

### Model Downloads in Toolbar

Model Downloads / Phantoms moved to a prominent position in the toolbar (previously buried in the Import/Export menu).

---

## 🛠 Fixed

### Workbench Stability

Multiple issues that would make the application freeze, become unresponsive, or prevent the mode buttons (Model/Sim/PP) from becoming visible.

- A workbench in a faulty state (e.g. errors in the postpro-pipeline indicated by red triangles in the analysis tree) would cause a validation error when the project is loaded, preventing mode buttons from showing due to an interrupted frontend/backend handshake.
- Certain modifications in the algorithm pipeline would trigger an infinite loop of changes between the workbench and algorithm tree, making the application busy indefinitely.
- Certain signals for changes in the workbench were emitted from a backend thread, causing crashes.

### Waveguide Source Settings

Waveguide source settings showing incorrect values in workbench; also fixed validation errors on malformed workbenches.

### Task Manager Crash

Filtering in Task Manager caused a UI crash when `task.extendedInfo` arrived as `null` from the backend.

### Viewport Cursor Coordinates

Cursor coordinates were not displayed in the viewport (hidden with `showCursor={false}`).

### Colorbar Positioning

Colorbars now stack vertically and the floating toolbar correctly reserves space only when colorbars are visible.

### Video Streaming

Pion WebRTC libraries updated — bandwidth estimation now uses encoder target bitrate directly instead of the BWE target (partial fix for video streaming locked at low bitrate).
