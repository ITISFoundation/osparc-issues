# Release Notes

### Version 9.6.0 · June 4, 2026

Sim4Life V9.6 is the second release in our application-driven computational neurostimulation series. This release addresses one of the field's most persistent bottlenecks: the time required to predict neural activation with biophysical realism.

For additional functionalities available in Sim4Life V9.6, please refer to:
https://sim4life.swiss/release-history

***

## ✨ Added

### Modeling

Model anonymization for privacy-aware data handling, compatible with the TIP tool.

### Simulation

#### T-Neuro

Fast prediction of neural responses for detailed biophysical models used in treatment-planning workflows.

Accelerated GAF predictor support for MRG-type double-cable axon models representing sensory and motor fibers.

Neural activation threshold prediction up to 1000× faster than conventional neuron simulations.

Automated recruitment-curve analysis for evaluating fiber activation by stimulation amplitude and comparing stimulation strategies.

#### Thermal Solver

Enhanced interpolation handling.

Plausibility check to verify overlap between EM simulation source domains and the thermal simulation domain.

#### FDTD Solver

Check added to verify sufficient padding around far-field sensors.

#### Voxeling

Standardized edge-normal computation across the Topological and Intersection voxelers, with parity validation tests to improve compatibility in thermal simulation workflows.

### Analysis

Reorganized dosimetry algorithms by output field type, including SAR and E-field algorithms.

Algorithm subcategories added to the algorithm tree for easier navigation.

### Python

New Scripter panel for writing and running Python scripts directly in the application, including auto-save before run, interrupt/stop support, clearer toolbar actions, running-tab indication, improved file dialogs, and a status bar.

Extended **To Python** export for more complex analysis workflows, including RCS-related paths and statistics evaluator outputs.

Exported Python for analysis pipelines now aligns with evaluator outputs and table-style results configured in the UI.

Improved Python API usability with stricter type handling, compatibility helpers, and more robust material-database API paths.

Writes to inactive settings are now policy-controlled with `ignore`, `warn`, and `raise`.

Assigning non-existing settings properties now raises `AttributeError` immediately.

Extended Waveguide and Acoustics APIs for better scriptability in setup workflows.

Python script execution can now be interrupted with the **Stop** button in the pop-up window.

### User Experience

Non-blocking execution for long-running operations such as meshing and rendering.

Support for NVIDIA Blackwell GPUs in cloud-based optimization workflows.

Improved feedback during project loading and initialization.

Enhanced 3D view responsiveness.

Faster download of remotely simulated cloud results.

New startup welcome screen with quick actions, recent files, embedded user manual, walkthroughs, and release notes.

Improved tool-selection dialog for large entity sets, including named folders, selection-count badges, per-bucket clear actions, and better resizing and scrolling.

Updated compressed backend/frontend transport for faster communication and reduced startup time.

Documentation, search, and notebook tutorials are now served from a dedicated documentation service, enabling independent documentation updates.

***

## 🛠 Fixed

### File Handling

Fixed corrupted-file generation when saving large meshes in ACIS formats (`.sab`, `.sat`, `.smash`).

Fixed an issue where the tissue list was saved to the wrong directory when exporting a segmentation with **Export tissue list** enabled.

### Analysis and Python

Fixed **To Python** generation for the RCS evaluator flow in the Analysis tab.

### Geometry and Mesh Interaction

Improved geometry snapping and picking reliability for vertices, edges, and model entities.

Fixed normal-generation issues and corrected edge-normal computation in the Topological Voxeler.

Fixed an issue with selecting patches on unstructured meshes.

### Interface and Visualization

Restored hover and focus highlighting on tree items and other UI components.

Picker windows, including Simulation Picker and Tool Selection, now open with responsive sizing instead of fixed dimensions.

Fixed the WebRTC video stream going black when opening or closing the welcome page.

Fixed expanded toolbar tools not responding to clicks.

Fixed the plot legend to display only visible traces.

Improved cursor-position label placement to prevent viewport overflow and jitter.

Improved 3D view mouse responsiveness through coalesced mouse-event handling.
