# Release Notes

### Version 9.4.2 · April 16, 2026

Stability and performance improvements with faster startup and better video streaming.

---

## ⚡ Changed

### Optimized Startup

Optimized startup procedure — the initial splash screen disappears quicker. If the previous smash file is loaded, the application now shows a busy dialog with more detailed logs.


---

## 🛠 Fixed

### Task Manager Crash

Fixed crash in Task Manager.

### Mode Tabs Disappearing

Fixed another instance of modeling/sim/pp tabs disappearing.

### Notification Overlap

Task Manager button no longer overlaps with notifications.

### Colorbar Safe Zone

Fixed colorbar safe zone boundaries.

### Video Streaming

Several improvements in video streaming — bandwidth should no longer stall.

### Tree Loading

Fixed edge case when trees would not or only partially get updated after loading smash files.

### Missing Icon

Fixed missing icon error message (touchstone_importer.ico).
