# Release Notes

### Version 1.92.0 · May 19, 2026

Better troubleshooting. Clearer feedback.

Improves how the platform explains computational problems, and adds a few quality-of-life touches that make daily workflows easier to follow.

---

## ✨ Highlights

### 🛠 Clearer Computational Runtime Errors

When a computation fails, the platform now gives you more helpful feedback.

Runtime errors are now displayed with improved messages, tooltips, and troubleshooting hints, making it easier to understand what happened and what you might try next.

For example, when a computation runs out of memory or reaches a timeout, the error message should now give you a clearer idea of what went wrong instead of leaving you with a cryptic failure.

Less guessing, more guidance.

### 📋 A Better Log Viewer

Logs just became easier to inspect.

Clicking on a log entry now opens a cleaner popup view with the full message, log level, timestamp, related node, and a copy-to-clipboard button.

Small detail, big quality-of-life improvement — especially when you are debugging a workflow and need the full story, not a cropped line.

### 💾 File Sync Feedback

When files are being synchronized in the background, the platform now tells you.

You’ll see feedback in the navigation bar while files are queued or uploading, so it’s clearer when the system is still working behind the scenes.

## 🛠 Fixes & Stability Improvements

This release also includes several fixes and refinements, including:

- **Notification emails are more reliable** and should now display more consistently across email clients.
- Selecting searched folders now behaves more predictably.
- General stability and maintenance improvements across the platform.
