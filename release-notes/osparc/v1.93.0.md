# Release Notes

### Version 1.93.0 · June 4, 2026

Support is harder to miss. Details are easier to read. Tiny popups finally learned where they belong.

This release focuses on small but meaningful improvements across the user interface — especially around the **Support Center**, workbench details, and everyday interactions that help you stay oriented while building and debugging.

---

## ✨ Highlights

### 🛟 Support Center: Easier to Follow, Harder to Miss

The **Support Center** keeps getting more helpful.

From now on, when the Support Team replies to one of your conversations and you are not online, you will receive an **email notification**.

On the other hand, if you are online, the **question-mark icon** in the navigation bar now blinks when a new message arrives, making support replies much easier to spot.

Small detail, big difference — especially when you are waiting for help and switching between tasks.

---

### 📡 Platform Status, Closer at Hand

A **Status** link is now shown in the login footer, making it easier to check platform availability when something does not seem quite right.

A small addition, but a useful one when you want to quickly know whether the issue is local or platform-wide.

---

### 🧪 Clearer Parameter and Probe Details

Parameters and Probes are now easier to recognize in the workbench.

The secondary panel now shows the **name of the selected parameter or probe** at the top, making it clearer which node you are inspecting or editing. Furrhermore, probes will also show the value they are measuring there, a space with more room for those values that don't fit well in the Node.

It is a small UI improvement, but a very welcome one when working with larger pipelines where “wait, which parameter am I looking at?” can happen surprisingly fast.

---

### 🪟 Popups That Stay Close to the Action

Rename and edit dialogs now open closer to the UI element that triggered them.

This improves the flow for actions such as:

* Editing a Support Center message
* Renaming a Support conversation
* Renaming a node from the tree

Instead of appearing somewhere unexpected, popup windows now feel more connected to what you were doing.

Less mouse travel. Less context switching. More “ah yes, there it is”.

---

## 🛠 Fixes & Stability Improvements

This release also includes several fixes and refinements, including:

* General maintenance, dependency updates, and backend stability improvements.
